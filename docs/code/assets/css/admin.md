# `assets/css/admin.css`

**Purpose:** light styling for the plugin's admin pages, on top of WordPress's own admin styles: white cards (`.itcp-card`, red border for the danger zone), the search row, origin badges (`.itcp-badge-default/-edited/-custom`), inline row forms, the checkbox grid (`.itcp-checkbox-group`), and the error list. Everything is scoped under `.itcp-admin`.

## Relations

- Loaded by: [`AdminAssets`](../../src/Admin/AdminAssets.md) on plugin pages only. Classes used in [`templates/admin/`](../../templates/admin/roles-list.md).
- No functions.
